## 📌 Project Overview

This project focuses on analyzing OLA ride-booking data to understand
business performance and identify meaningful operational insights.

The analysis involves cleaning and transforming 100,000+ ride records,
answering business questions using SQL, and developing an interactive
Power BI dashboard to visualize key performance indicators.

The project aims to identify booking trends, cancellation patterns,
revenue distribution, vehicle performance, and customer behaviour
through data-driven analysis.

**Current Status:** 🚧 Work in Progress

## 🎯 Project Objectives

-   Analyze overall ride-booking performance.
-   Identify successful and cancelled booking trends.
-   Evaluate vehicle-wise ride distance and performance.
-   Understand customer and driver cancellation patterns.
-   Analyze revenue across different payment methods.
-   Identify top-performing customers.
-   Explore customer and driver rating patterns.
-   Generate actionable business recommendations.
